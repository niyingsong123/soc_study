当前按系统管理网络主题建立入口，具体英文全称、目标设计职责与父级等待资料确认。

与 CF 分开管理；与 SMU/RSMU 连接不等于属于它们。

学习问题：寄存器访问如何寻址、仲裁、返回和报错；上电、复位和调试时如何工作；与管理控制器如何交互。当前仅有用户提供的模块名称。
